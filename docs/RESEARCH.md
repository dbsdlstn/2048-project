# Neon Rift 외부 자료 조사 노트

- 조사일: 2026-11-13 (프로젝트 상태: 1단계 완료, 2단계 진행 중)
- 목적: 배우거나 가져올 만한 외부 자료를 골라, **어느 단계·어느 파일에 반영할지** 판정해 둔 문서. 후속 조사 때 이 파일에 이어 붙인다.
- 원칙: 다른 게임의 이름·아트·레벨·외형은 가져오지 않는다. 아이디어와 패턴만 참고한다. 런타임 의존성 0을 기본값으로 둔다.
- 표기: 판정은 **채택 권장 / 아이디어만 참고 / 보류**. 비용은 작음(반나절 이하) / 중간(1~2일) / 큼(그 이상).
- 확인 수준: `[확인]` 해당 페이지를 직접 열어 봄 · `[2차]` 검색 결과나 요약 글로만 확인 · `[미확인]` 확인 못 함. 자세한 목록은 맨 끝 "확인하지 못한 것".

## 8. 단계별 반영 체크리스트

- **2단계(진행 중)**: 글로우 스프라이트 캐시 · 렌더러 시계 주입 · `?seed=`/`?debug` 훅과 상태 텍스트 덤프 · 고정 시드 Playwright 스모크(상태 단언 + 스크린샷 저장) · 연출 중 입력 버퍼링 방침
- **3단계**: 유물 설계 규칙 문서화 후 15종 재검토 · `TurnEvent`에 단계(phase) 개념 여부 결정 · 정보 공개 원칙(남은 턴·절반 예고 표시) · 밸런스 봇(무작위/탐욕/구석) · 방해 타일은 형태로 구분
- **4단계**: 1막 1~3스테이지를 튜토리얼로 · 오늘의 시드(결정되면) · 저장 데이터에 밸런스 버전 표기
- **5단계**: trauma 흔들림 · 이벤트→연출 매핑 표 · 콤보 음높이 상승과 엇갈린 팝 · 히트스톱(드문 사건만) · 파티클 풀 · 오디오 잠금 해제 · 안드로이드 진동 · "움직임 줄이기"/소리/진동 설정 · 실제 폰에서 프레임 시간 측정
- **6단계**: `vite-plugin-pwa` · 코드 생성 아이콘 · Pages 워크플로 · 오프라인 Playwright 테스트 · 번들 크기 상한 스크립트 · README에 연출 전후 비교와 봇 시뮬레이션 결과
- **전 단계(작업 방식)**: 수용 기준 선작성 · 증거 필수 보고 · 읽기 전용 리뷰어 · `playtest` 스킬

## 9. 확인하지 못했거나 불확실한 것

- **접근 차단**: `reddit.com`(LocalThunk 원문). 지침 내용은 검색 요약에만 근거함.
- **영상 미시청**: GDC·YouTube 강연들(Eiserloh, Jonasson & Purho, Vlambeer, Giovannetti, George Fan)은 존재와 요지를 2차 자료로만 확인. 히트스톱이 어느 강연에 나오는지는 미확인.
- **iOS 관련 전부 실기기 미검증**: `switch` 체크박스 햅틱(사파리 17.4 이상이라는 것도 2차 정보), `navigator.audioSession`, 무음 스위치 동작.
- **글로우 성능**: "`shadowBlur`가 느리다"는 MDN 권고와 사례 보고에 근거. 이 프로젝트에서 실제로 몇 ms 차이가 나는지는 측정해 봐야 함.
- **Playwright Clock이 `performance.now()`를 제어하는지** 문서에 명시 없음.
- **Lighthouse PWA 카테고리 제거 버전**(12.x로 추정)과 현재 개별 감사 실행 방법.
- **GitHub 최종 커밋 날짜**: 대부분 페이지에서 보이지 않아 npm 레지스트리의 수정일로 대신함(메타데이터 변경일일 수 있음).
- **gabrielecirulli/2048의 내부 파일 구성**은 기억에 근거. rotjs-basic-bones, 2048 Dungeons, 2048: Worlds of Time, 봇 밸런싱 개발 일지는 검색 결과로만 봄.
- **`develop-web-game` 스킬 원문**, `anthropics/skills`의 `webapp-testing` 본문, Game-Studios의 개별 스킬 내용은 읽지 못함.
- **TWA와 github.io 프로젝트 경로**의 `assetlinks.json` 제약은 문서 내용에서의 추론.
- **web-haptics**가 React/Vue/Svelte를 peer로 선언하는데 선택 사항인지 미확인.
